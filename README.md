# MTHM504
Summer project for Applied Data Science and Statistics MSc:

To what extent are “selection biases” present in the recruitment of adolescent Track and Field (Athletics) athletes onto England Athletics’ Youth Talent Programme between 2021 and 2025? 

My area of interest is sociodemographic selection biases so I specifically focused on the following biases:
- relative age effect
- geographical representativeness

This repository should contain everything relating to my project, including all code used for results, my notes, and final write-up (?) but NOT the data for obvious privacy reasons.
