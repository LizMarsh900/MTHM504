# MTHM504
Summer project for Applied Data Science and Statistics MSc at the University of Exeter:

To what extent are “selection biases” present in the recruitment of adolescent Track and Field (Athletics) athletes onto England Athletics’ Youth Talent Programme between 2021 and 2025? 

My area of interest is sociodemographic selection biases so I specifically focused on the following biases:
- relative age effect
- geographical representativeness

This repository is mostly for storing my code because a main focus of the project was reproducibility and recyclability of code. But there are other folders for other relevant bits and bobs, just NOT the data for obvious privacy reasons.
